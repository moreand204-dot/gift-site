# A Gift To My Future Wife — هدية لـ Manon

موقع هدية رومانسية بأسلوب Dark Luxury، بوابة كلمة سر، وتجربة "كتاب فصول" (14 فصل) بدل الـ Scroll اللانهائي.

## 🚀 التشغيل

```bash
cd gift-site
python3 -m http.server 8080
```
افتحي `http://localhost:8080` محليًا. لو بترفعيه على Vercel/Netlify/GitHub Pages، ارفعي المجلد كله زي ما هو — مفيش أي إعداد إضافي مطلوب، هو موقع ثابت (Static).

## 🎵 تشغيل الأغنية (كان فيه مشكلة — اتصلحت)

المشكلة كانت إن الكود كان بيدور على ملف اسمه literally `{{BACKGROUND_MUSIC}}.mp3` (نص الـ placeholder نفسه) بدل اسم ملف حقيقي.

**الحل دلوقتي:** حطي ملف الأغنية في `assets/music/` وسمّيه **`song.mp3`** (أو `song.m4a` / `song.wav` / `song.ogg`) — الكود بيدور عليه أوتوماتيك ويشغّله من غير ما تلمسي أي كود. لو عايزة اسم مختلف، افتحي `js/music.js` وضيفي اسم الملف في أول مصفوفة `CANDIDATES`.

تأكدي إن اسم الملف مطابق بالظبط (حساس لحالة الحروف) وإنه فعلاً جوه `assets/music/` مش في مكان تاني.

## 🔊 المؤثرات الصوتية — بقت مُولّدة بالكود، مش ملفات

بدل ما تحتاجي تجيبي ملفات mp3 لكل مؤثر (دقة قلب، قلم بيرسم، تقليب صفحة، فتح هدية، سقوط ورد، مطر، رعد)، كل ده بقى بيتولّد لحظيًا بالكود عن طريق Web Audio API — موجود في `js/sfx.js`. معنى كده إن مفيش أي ملف ممكن "يضيع" أو "يبقى مساره غلط" — شغال دايمًا. لو عايزة تغيّري طابع أي صوت (نغمة، مدة، تردد)، كله موجود ومعلّق عليه في `js/sfx.js`.

الرسالة الصوتية الحقيقية اللي بعتيها لسه موجودة كملف حقيقي في فصل "الرسائل" (`assets/messages/voice-note-01.mp3`) مع مشغّل صوت مباشر.

## 🔐 كلمة السر

بتقبل: إسكانور، اسكانور، عبدالرحمن، إيسو، جوزي، حياتي، روحي، قلبي، ابني، سندي، عبدو، عبود، بودي، بودا (من غير حساسية لشكل الهمزة). تقدري تعدّلي القائمة من `js/gate.js`.

## 📖 الفصول الأربعتاشر

البداية ← الذكريات ← المشاكل ← الصلح ← الضحك ← الهزار ← النكش ← الغيرة ← الشعر ← القصائد ← الرسائل ← الأحلام ← المستقبل ← النهاية.

كل فصل (غير الأخير) بينتهي بسطر شعري قصير قبل زرار "جاهزة للقسم اللي بعده؟" — تقدري تغيّريه بسهولة، هو نص عادي جوه `<p class="chapter-closing">` في ملف كل فصل بمجلد `sections/`.

الانتقال بين الفصول: شاشة سوداء + القلم الذهبي بيرسم قلب صغير + كلمة عشوائية (بحبك / اسمها / قلبي...) قبل ما يظهر زرار الانتقال الفعلي.

**النصوص الجاهزة فعلاً:** البداية، المشاكل، الصلح، الهزار، النكش، القصائد (كاملة)، الرسائل، المستقبل، النهاية.
**لسه محتاجة نص منك** (فيها ملاحظة صفراء `placeholder-note` في الموقع نفسه): الذكريات (مقدمة قصيرة)، الضحك، الغيرة، الأحلام.

## 🖼️ الصور والسكرين شوتس

كل الصور (سكرين شوتس المحادثات) بقت في `assets/images/` مباشرة (مسار مبسّط، من غير مجلد فرعي `screenshots/`). توزيعها على الفصول حسب المزاج:
- **الذكريات**: chat-02, chat-09
- **الصلح**: chat-07
- **الغيرة**: chat-11
- **الهزار**: chat-03, chat-05, chat-08, chat-10
- **الضحك**: chat-13, chat-14, chat-15
- **النكش**: chat-12, chat-16
- **الرسائل**: chat-01, chat-04, chat-06

لو عايزة تغيّري صورة مكان صورة، افتحي ملف الفصل في `sections/` وغيّري `assets/images/chat-XX.jpg` باسم الصورة اللي عايزاها.

## 🎨 الأيقونات

كل الأيقونات SVG احترافية عن طريق مكتبة **Lucide** — مفيش Emoji في التصميم خالص.

## ✅ تشيك ليست قبل ما تبعتيه

- [ ] استبدلتِ باقي الـ `{{...}}` في `sections/*.html` (تواريخ الـ Timeline، صور المعرض، أحلام المستقبل، إلخ)
- [ ] كتبتِ نص الفصول الناقصة (الذكريات، الضحك، الغيرة، الأحلام)
- [ ] حطيتِ `assets/music/song.mp3`
- [ ] جربتِ الموقع كامل من الأول للآخر على الموبايل (كلمة السر → كل الفصول → النهاية)
