# A Gift To My Future Wife — موقع تفاعلي (نسخة الفصول)

موقع هدية رومانسية بأسلوب Dark Luxury، بوابة كلمة سر، وتجربة "كتاب فصول" — كل قسم فصل مستقل من غير Scroll لا نهائي، بينتقل للتاني بانتقال سينمائي فيه قلم ذهبي بيرسم كلمة عشوائية.

## 🚀 التشغيل

```bash
cd gift-site
python3 -m http.server 8080
```
افتحي `http://localhost:8080` (لازم خادم محلي عشان تحميل الأقسام يشتغل — المتصفح يمنع `fetch()` مع `file://`).

## 🔐 كلمة السر

شاشة الدخول بتقبل أي من الكلمات دي (بدون حساسية لأشكال الهمزة): إسكانور، اسكانور، عبدالرحمن، إيسو، جوزي، حياتي، روحي، قلبي، ابني، سندي، عبدو، عبود، بودي، بودا.
تقدري تعدّلي القائمة من `js/gate.js` (مصفوفة `ALLOWED`).

## 📖 الفصول الأربعتاشر

بالترتيب: البداية ← الذكريات ← المشاكل ← الصلح ← الضحك ← الهزار ← النكش ← الغيرة ← الشعر ← القصائد ← الرسائل ← الأحلام ← المستقبل ← النهاية.

كل فصل ملف مستقل في `sections/`. للانتقال، المستخدم يدوس زرار "جاهزة للقسم اللي بعده؟"، فتتلاشى الشاشة، يرسم القلم كلمة عشوائية (بحبك / اسمها / قلبي / روحي...)، وبعدين يظهر زرار الانتقال الفعلي.

**النصوص الجاهزة فعلاً** (من الرسايل اللي بعتيها): البداية، المشاكل، الصلح، الهزار، النكش، القصائد (القصيدة كاملة)، الرسائل، المستقبل، النهاية.

**لسه محتاجة نص منك** (فيها ملاحظة `placeholder-note` صفراء في الموقع نفسه): الذكريات (مقدمة قصيرة)، الضحك، الغيرة، الأحلام. مقصود اسيبهم فاضيين بدل ما أختلق كلام رومانسي نيابة عنك.

## 🖼️ لقطات المحادثات

الصور الـ16 اللي بعتيها اتوزعت على الفصول حسب المزاج:
- **الذكريات**: chat-02, chat-09 (حياة يومية)
- **الصلح**: chat-07 (رسالة اعتذار)
- **الغيرة**: chat-11
- **الهزار**: chat-03, chat-05, chat-08, chat-10
- **الضحك**: chat-13, chat-14, chat-15
- **النكش**: chat-12, chat-16
- **الرسائل**: chat-01, chat-04, chat-06 + الرسالة الصوتية

كل صورة جوه إطار (`chat-frame`) بلون مناسب للمزاج (هادئ / عاصفة / صلح / مرح). لو عايزة تغيّري توزيع الصور، افتحي ملف الفصل المناسب في `sections/` وغيّري اسم الصورة.

## 🔊 المؤثرات الصوتية

الموقع بيحاول يشغّل ملفات صوت تلقائي في لحظات معينة (دقة قلب، قلم بيرسم، تقليب صفحة، فتح هدية، سقوط ورد، مطر ورعد) لكن لازم تحطي ملفات الـ mp3 الحقيقية في `assets/sfx/` بنفس الأسماء الموضحة في `assets/sfx/README.txt`. لو الملف مش موجود، الموقع هيتجاهله بهدوء من غير أي خطأ يظهر.

الموسيقى الخلفية: حطي الملف في `assets/music/` وسمّيه بنفس اسم الـ placeholder `{{BACKGROUND_MUSIC}}` في `index.html` (أو استبدلي الـ placeholder باسم الملف مباشرة). بتشتغل أوتوماتيك أول ما تدخل الرحلة، ومعاها زرار تشغيل/إيقاف تحت يسار الشاشة.

الرسالة الصوتية اللي بعتيها اتحطت في فصل "الرسائل" (`assets/messages/voice-note-01.mp3`) مع مشغّل صوت مباشر.

## 🎨 الأيقونات

كل الأيقونات SVG احترافية عن طريق مكتبة **Lucide** (`data-lucide="..."` + `lucide.createIcons()`) — مفيش Emoji في التصميم خالص، حتى القلوب والورود في المؤثرات مرسومة بـ SVG.

## 📁 هيكل المشروع (محدّث)

```
index.html              → البوابة + الافتتاحية + حاوية الفصول
css/
  main.css               → المتغيرات + الأساسيات + [data-reveal]
  animations.css
  responsive.css
  pages/
    gate.css              → شاشة كلمة السر
    intro.css              → الافتتاحية السينمائية
    chapters.css            → نظام التنقل بين الفصول + شاشة الانتقال
    timeline.css / gallery.css / poems.css / future.css
    moods.css               → إطارات السكرين شوتس + فصول الضحك/الهزار/النكش/الغيرة/الأحلام/الرسائل
js/
  gate.js               → منطق كلمة السر
  loader.js             → تحميل الفصول + بدء الافتتاحية بعد الدخول
  chapters.js            → التنقل بين الفصول + انتقال القلم
  particles.js / cursor.js / effects.js / scroll.js
  timeline.js / book.js / gallery.js / music.js / main.js
sections/
  01-beginning.html … 14-ending.html
assets/
  images/screenshots/    → لقطات المحادثات الـ16
  messages/               → الرسالة الصوتية
  music/                  → الموسيقى الخلفية (لسه محتاجة تضيفيها)
  sfx/                    → المؤثرات الصوتية (لسه محتاجة تضيفيها) + README.txt بأسماء الملفات
```

## ✍️ باقي الـ Placeholders

دوري على `{{...}}` في ملفات `sections/*.html` واستبدليها — القائمة الكاملة (تواريخ الـ Timeline، صور المعرض، أحلام المستقبل، إلخ) لسه زي ما كانت في النسخة الأولى.
